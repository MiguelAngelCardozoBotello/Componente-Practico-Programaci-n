# Componente Práctico - Programación
## Fase 4 - Ejercicio 1
Sistema Integral de Gestión de Clientes, Servicios y Reservas

## Descripción del proyecto
Este proyecto corresponde al desarrollo colaborativo de la Fase 4 del curso Programación. El sistema tiene como objetivo gestionar clientes, servicios y reservas para la empresa Software FJ, aplicando programación orientada a objetos, manejo de excepciones, validaciones y registro de eventos mediante archivos de logs.

## Objetivo del proyecto
Desarrollar un sistema integral orientado a objetos, estable, modular y extensible, que permita gestionar clientes, servicios y reservas sin el uso de bases de datos, utilizando clases, objetos, listas internas y archivos para el registro de eventos y errores.
